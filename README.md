# SAGS LINK HUB

Trang truy cập tập trung các ứng dụng làm việc SAGS và các cổng hãng hàng không.

- Website sau khi bật GitHub Pages: **https://sagsdieuhanh-gif.github.io/hub/**
- Mã nguồn độc lập: **https://github.com/sagsdieuhanh-gif/hub**
- Toàn bộ 22 đường dẫn nằm trong `index.html` ở thư mục gốc.
- Logo SAGS được lưu trong repository này tại `assets/logo-sags.png`; không phụ thuộc vào repository Manager On Duty.
- Giao diện sáng, có tìm kiếm theo tên và đánh dấu yêu thích bằng bộ nhớ trình duyệt.

## Bật GitHub Pages lần đầu

1. Mở [Settings → Pages](https://github.com/sagsdieuhanh-gif/hub/settings/pages).
2. **Build and deployment → Source:** chọn **Deploy from a branch**.
3. **Branch:** chọn `main` và `/(root)`, sau đó nhấn **Save**.
4. Trang chủ sẽ được xuất bản tại `https://sagsdieuhanh-gif.github.io/hub/`.

Không cần dùng workflow hoặc repository BAOCAOMANAGERONDUTY để xuất bản HUB.

## Lưu ý

Một số đường dẫn bên ngoài yêu cầu đăng nhập; các địa chỉ `192.168.102.250` và `172.16.112.8` chỉ hoạt động trên mạng nội bộ phù hợp. Link HTTP không mã hóa đường truyền.
